# CLAUDE.md

Diese Datei liest Claude Code automatisch, wenn du es in diesem Projekt startest.
Sie gibt Claude Kontext über das Projekt und deine Arbeitsweise — so bekommst du
bessere und konsistentere Ergebnisse.

## Über dieses Projekt

Übungs-Repository zum Erlernen des Pull-Request-Workflows auf GitHub.
Es gibt (noch) keinen Anwendungscode — der Fokus liegt auf Git, sauberen
Commits und dem Review-Prozess.

## Konventionen

- Sprache in Dokumentation und Commit-Nachrichten: Deutsch.
- Kleine, fokussierte Commits mit aussagekräftigen Nachrichten
  (Was wurde geändert und warum?).
- Änderungen immer auf einem eigenen Branch entwickeln, nie direkt auf `main`.
- Formatierung folgt der `.editorconfig` im Projektstamm.
