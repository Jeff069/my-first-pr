# Mobile Simulator

Ein winziges, abhängigkeitsfreies Tool, das deine lokal laufende Web-App
in einem Handy-Rahmen anzeigt — praktisch, um es neben dein Terminal zu legen,
während du entwickelst.

## Benutzung

1. Starte deine App lokal (z. B. `npm run dev` auf `http://localhost:3000`).
2. Öffne `mobile-simulator/index.html` im Browser.
3. Trag die URL deiner App oben ein und klick auf **Laden**.
4. Mit **Neu laden** aktualisierst du die Ansicht nach Änderungen,
   mit **Drehen** wechselst du zwischen Hoch- und Querformat.

Kein Build-Schritt, kein npm install — einfach die HTML-Datei öffnen.
